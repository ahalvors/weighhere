# WeighHere

Find public vehicle scales for RVs, trucks, and trailers across California.

## Live Site

Visit [https://ahalvors.github.io/weighhere/](https://ahalvors.github.io/weighhere/)

## About

WeighHere helps RV owners, truckers, and anyone needing to weigh their vehicle find certified public scales. The site includes:

- Searchable scale listings by county
- CDFA certified scale locations
- CAT Scale network locations
- Comprehensive guide on how to weigh an RV
- Safety tips and weight rating information

## Data Sources

- California Department of Food and Agriculture (CDFA) certified scales
- CAT Scale network locations
- Public weigh station directories
- Community-verified locations

## Development

This is a static site built with HTML, CSS, and vanilla JavaScript. No build process required.

To run locally:
```bash
python -m http.server 8000
# or
npx serve .
```

## Contributing

Know of a public scale that's not listed? Please submit an issue or pull request with:
- Scale name
- Complete address
- Phone number
- Certification type (CDFA, CAT, etc.)
- Any special notes (hours, RV-friendly, etc.)
