# WeighHere

Static directory of **public vehicle scales for civilians** — U-Haul and moving trucks, RVs, horse trailers, boat/dump trailers, and military PPM/DITY loads — with a certified ticket when they need one, and a red flag on highway enforcement weigh stations.

Homepage **is** the Los Angeles County page. Orange County is a thinner, honest CDFA table. Inland Empire is ScaleRegistry Colton + Love’s CAT + Riverside County landfills (CDFA grids not loaded).

## Open it

On this machine:

```bash
cd /workspace/weighhere
python3 -m http.server 8080
```

Then open http://127.0.0.1:8080/

Or open `/workspace/weighhere/index.html` in a browser (map tiles and Google Fonts need a network; listings do not).

Deploy: drop the folder on Netlify. `netlify.toml` runs `python3 build.py` and publishes `.`.

## What’s in the box

| Path | Page |
|---|---|
| `/` and `/los-angeles/` | LA County listings (dedicated houses first, CAT/truck stops, call-first plants, I-405 Carson do-not-go) |
| `/orange-county/` | CDFA Orange County table + pointer to Santa Fe Springs |
| `/inland-empire/` | Colton public house, Love’s CAT in Barstow/Coachella, Riverside County landfill gates |
| `/how-to-weigh-an-rv/` | CAT platforms, no corners, 2,000 lb floor, printed CA ticket |
| `/ppm-dity-southern-california/` | Empty+full, weighmaster signature, CA print vs Weigh My Truck PDF |
| `/horse-trailer/` | CAT vs mill vs landfill, call-ahead script, no fake affiliate IDs |
| `/cat-2000-lb-minimum/` | Cars and light trailers; dedicated houses instead of CAT |
| `/public-scale-vs-weigh-station/` | Description of CHP vs ticket shops — not legal advice |
| `/about.html` | Sources, CDFA disclaimer, affiliate placeholder |

Data lives in `data/stations.json`. HTML is generated by `python3 build.py`. After you edit JSON, rebuild.

## Rules this repo already follows

- Public sources only (CDFA county tables, CAT public pages, operator sites, ScaleRegistry, Caltrans, Pilot location pages).
- No Penske / Trucker Path / AllStays scrape. No competitor dump.
- Missing hours/fees/livestock beat invented ones.
- Industrial CDFA rows are call-first.
- Do not send people to I-405 Carson for a ticket.

Nightly ship format: see `ADDING_A_PAGE.md`.
